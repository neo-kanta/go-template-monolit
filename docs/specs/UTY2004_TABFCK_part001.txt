一、UTY2004001：TACKLackDocRestrict
檢核受益人是否為缺件限制交易 Url：{root}/TAapi/BaseUtility/BFChkData/TACKLackDocRestrict
傳入參數
[TABLE]
欄位名稱	資料型態	Method\nQ	欄位說明	備註
公司代碼\nSysCoID	String	V
適用系統\nDocSys	String	V	1．選項(TA-900001)
戶號\nBFNo	Int	V
交易日期\nTxDate	DateTime	V
交易類別\nQueryType	String	V	1．選項(OPT：TA-900026)\n1：申購；2：買回；3：轉換；4：定額

邏輯說明
資料來源檔案
檢核受益人缺件限制交易(BizUtility.ChkBFLackDocRestrict)
資料處理說明
以傳入參數至【檢核受益人缺件限制交易(BizUtility.ChkBFLackDocRestrict)】取得資料
若「檢核失敗否(IsCheckFailed)」為『True』，則回傳結果代碼{TXN0054}

為『W.警示』，回傳結果代碼{TXN0055}
為『R.禁止』，回傳結果代碼{TXN0056}

四、UTY2004004：TACKBFAgreePayAcct

傳入參數
[TABLE]
欄位名稱	資料型態	Method\nQ	欄位說明	備註
公司代碼\nSysCoID	String	V
戶號\nBFNo	Int	V
查詢日期\nQueryDate	Datetime	V
查詢類別\nQueryType	String	V	1．選項\n01：投信付款-買回、02：投信付款-配息、\n21：投信付款-買回+集保付款、22：投信付款-配息+集保付款

邏輯說明

傳入參數
[TABLE]
欄位名稱	資料型態	Method\nQ	欄位說明	備註
公司代碼\nSysCoID	String	V
戶號\nBFNo	Int	V
查詢日期\nQueryDate	Datetime	V
同意書類別\nAgrDocType	String	V	1．選項(OPT：TA-000071)

邏輯說明
資料來源檔案
檢核受益人同意聲明書(BizUtility.ChkBFAgreeDocEff)
