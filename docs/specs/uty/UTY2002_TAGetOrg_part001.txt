通路代碼\nChannelCode	String	1．機構全碼(OrgFullCode)
通路簡稱\nChannelCodeNM	String	1．機構簡稱(OrgCodeNM)
大通路代碼\nChannelBCode	String	1．總機構代碼(OrgHeadCode)

邏輯說明
資料來源檔案
取得機構查詢資料(SysUtility.GetOrgV)：取得「資料查詢類別」為『2.通路』的資料
取得All選項查詢資料(SysUtility.GetSysAll)
資料處理說明
全部通路(@AllList)：若《含全部通路選項》為『True』時，至【取得All選項查詢資料(SysUtility.GetSysAll)】取得「All選項Key」為『Org』的資料
通路清單(@ChannelList)：依下述處理後再回傳結果
若《含全部基金選項》為『True』時，依據全部通路(@AllList)內容新增一筆資料，資料內容如下
「通路代碼」：為全部通路(@AllList)的『All選項代碼(AllValue)』
「通路簡稱」：為全部通路(@AllList)的『All選項名稱(AllName)』
其餘欄位為空值
資料排序說明
若《含全部通路選項》為『True』時，全部通路(@AllList)固定為第一筆

「通路簡稱」：為全部銷售機構(@AllList)的『All選項名稱(AllName)』
